PID 와 LQR — 카트-폴로 직접 튜닝해 보기

레일 위 카트에 힘을 주어 막대를 세웁니다. 슬라이더를 움직이면 실행 중에도 바로 반영됩니다. PID 는 막대 각도 하나만 보고, LQR 은 위치 · 각도 · 속도 · 각속도 4개를 한꺼번에 봅니다. 마지막 절의 명령으로 같은 실험을 MuJoCo 에서도 돌려 숫자를 비교해 보세요.

① 각도 PID 의 한계

막대는 1 초 안에 서지만 카트가 0.3 m/s 로 계속 밀려갑니다. 외란 뒤 더 빨리 밀려 약 5 초에 레일 끝(±2.9 m)에서 넘어집니다. 각도 오차만 0 으로 만들 뿐 카트 위치는 PID 의 관심 밖입니다.

② 이득 바꾸기

  • Kd 0 감쇠가 없어 ±5° 진동이 계속
  • Kp 15 기울기를 못 따라가 2.3 s 만에 넘어짐
  • Ki 50 밀려남이 줄지만 외란을 넣으면 결국 넘어짐

외란 0 N 으로 놓고 비교하면 차이가 잘 보입니다.

③ 캐스케이드 PID

바깥 루프가 목표 각도 = −(Kx(x−target) + Kv·ẋ) 를 정합니다. 부호가 직관과 반대입니다. 카트를 +x 로 보내려면 먼저 −x 로 살짝 빼서 막대를 +x 로 기울여야 하기 때문입니다. 이득 5개를 손으로 맞춰야 합니다.

④ LQR

K 4개를 비용 Q, R 에서 계산합니다. 기본값으로 10 s 에 x = 1.000 m, 외란도 받아냅니다. R=10 이면 힘을 아껴 느려지고(외란 없이 약 12 s 에 1 m), 3 N 외란을 넣으면 힘이 모자라 5.2 s 에 레일 끝에서 넘어집니다. Q 각도를 키우면 막대를 더 꼿꼿이 세웁니다. 캐스케이드의 반대 부호는 K 안에 이미 들어 있습니다(위치 · 각도 이득 부호가 같음).

핵심 코드

PID — pid.py

error = measured - self.setpoint
self.integral += error * dt
derivative = (error - self.prev_error) / dt
u = kp * error + ki * self.integral + kd * derivative

LQR — lqr.py

# x[k+1] ≈ A x[k] + B u[k]  (수치 미분, 식 유도 없음)
mujoco.mjd_transitionFD(model, data, 1e-6, True, A, B, None, None)
P = solve_discrete_are(A, B, Q, R)
K = np.linalg.solve(R + B.T @ P @ B, B.T @ P @ A)
u = -K @ (np.concatenate([data.qpos, data.qvel]) - goal)

이 페이지의 LQR 도 같은 순서입니다. 브라우저 물리 한 스텝을 중앙 차분으로 미분해 A, B 를 얻고, 리카티 반복으로 K 를 구합니다.

python lessons/02_control/lqr.py                                            # ④ LQR
python lessons/02_control/lqr.py --q 1 1 1 1 --r 10 --seconds 20 --push 0

python lessons/02_control/lqr.py --viewer       # 아무 명령에나 --viewer 를 붙이면 MuJoCo 창
python lessons/02_control/test_control.py       # ok
